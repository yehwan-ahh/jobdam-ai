# 잡담(Job談) 3분 시연 시나리오

- 주소: https://jobdam.streamlit.app (시연 10분 전에 한 번 열어 앱을 깨워 두기)
- 화면: 노트북 전체 화면, 브라우저 확대 100%
- 가상 인물: **"민지"**, 지방 4년제 경영학과 4학년, 게임을 좋아하지만 비전공이라 망설이는 중
  (실제 개인정보는 쓰지 않습니다. 대회 규칙: 외부 AI에는 가상 데이터만)

| 시간 | 화면 | 말할 내용 (발표자) | 클릭·입력 |
|---|---|---|---|
| 0:00–0:25 | 대시보드 | "주변에 물어볼 현직자가 없으면 진로 정보는 커뮤니티 후기에 기대기 쉽습니다. 잡담은 현직자 AI 패널과 '3년 뒤의 나'가 공공데이터를 근거로 함께 고민해 주는 에이전트입니다." | 대시보드 첫 화면, 사이드바 "연결 상태" 배지 가리키기 |
| 0:25–1:20 | 직무 패널 | "민지는 게임을 좋아하지만 비전공자입니다. 관심 분야를 고르면 직무별 페르소나가 패널로 등장합니다." | 관심 분야 **게임 개발** → 카드 3장 보여 주기 → 질문 입력: **"비전공자인데 게임 기획자가 될 수 있을까요?"** |

| 2:45–3:00 | 데이터와 원칙 | "모든 답은 커리어넷·KOSIS 공공데이터를 근거로 하고, 추정은 추정이라고 밝힙니다. 잡담은 정답을 주기보다 여러 길을 비교해 보게 돕습니다." | 데이터와 원칙 페이지 → 통계표 목록 보여 주고 마무리 |

## 준비물 체크
- [ ] 시연 10분 전 사이트 열어 깨우기, 연결 상태 배지 3개 확인
- [ ] 질문 3개를 메모장에 미리 적어 두고 복사·붙여넣기 (오타 방지)
- [ ] 와이파이 끊김 대비: 같은 흐름을 녹화한 영상(1분 30초) 준비
- [ ] 팀 키 질문 제한(접속당 20개) 안에서 리허설하기

## 예상 질문과 답변 (QA 5분 대비)
- **AI가 틀린 말을 하면?** → 근거자료에 있는 내용만 사실로 말하게 하고 출처를 붙입니다. 숫자는 공공데이터에 있을 때만 말하고, 화면에 "참고 자료이며 상담을 대신하지 않는다"고 안내합니다.
- **개인정보는?** → 받지 않고 저장하지 않습니다. 전화번호·이메일·주민번호는 AI에 보내기 전에 차단합니다.
- **비용은?** → 팀 키는 접속당 질문 20개로 제한하고, OpenAI 월 사용 한도를 걸어 둡니다. (발표 전 실제 설정 확인 필요) 원하는 사용자는 자기 키를 쓸 수 있습니다.
- **확장성은?** → 직무 분야와 통계표를 데이터로 관리해서 분야 추가가 쉽고, 학교 진로센터·청년센터에 붙일 수 있습니다.
