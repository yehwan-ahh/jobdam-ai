## 01 문제 정의

**한 문장 문제**: 청년은 직무의 현실을 모른 채 첫 직장을 고르고, 그 결과 1년 반 만에 떠난다.

| 지표 | 수치 | 출처 |
|---|---|---|
| 첫 직장 평균 근속기간 | 1년 6.8개월 | 통계청 경제활동인구조사 청년층 부가조사(2026.5) |
| 첫 직장을 그만둔 이유 1위 | 근로여건(보수·근로시간) 불만족 44.4% | 같은 조사 |
| 졸업 후 첫 취업까지 | 평균 11.2개월 | 같은 조사 |
| 전공 분야 미스매치 | 한국 49% (OECD 평균 38%) | 국회미래연구원(2026) |

**왜 이런 일이 생기나 (원인 3가지)**
1. **물어볼 사람이 없다**: 현직자 인맥은 학교·지역·전공에 따라 크게 갈리고, 비전공자일수록 실제 일과·연봉·준비 방법을 들을 기회가 적다.
2. **믿을 숫자가 없다**: 커뮤니티 후기는 출처가 없고, 공식 데이터(고용24·KOSIS)는 신뢰할 수 있지만 표가 복잡해 내 질문에 맞게 읽기 어렵다.
3. **길을 나란히 놓고 볼 곳이 없다**: 취업·대학원·창업을 같은 기준(임금·취업률·생존율)으로 비교해 주는 도구가 없다.

→ 잡담은 "**근로여건을 미리 알고 고르는 것**"을 돕는다. 들어가기 전에 연봉·일과·힘든 점을 공식 숫자와 현직자 관점으로 확인하게 한다.

## 02 대상 사용자

**주요 사용자 (Primary)**: 진로 결정을 앞둔 대학교 3~4학년·졸업 예정자
- 대표 페르소나 **민지(경영학과 4학년, 가상 인물)**: "마케팅을 하고 싶은데, 신입 연봉이 얼마인지, 실제로 무슨 일을 하는지, 대학원을 가는 게 나은지 모르겠어요. 물어볼 선배가 없어요."
- 함께 해당: 전공과 다른 직무를 고민하는 비전공자, 첫 직장 1~2년 차에 이직을 고민하는 사회초년생

**보조 사용자·이해관계자**: 대학 진로·취업센터 상담사(상담 전 사전 탐색 도구), 청년센터·고용센터(상담 인력 보완), 공공데이터 제공기관(활용 확산)

**사용자가 얻는 가치 (Before → After)**

| Before | After (잡담) |
|---|---|
| 아는 선배가 없으면 현실을 못 들음 | 직무 선배 AI에게 언제든 묻고, 다른 직무 선배 2명의 관점까지 비교 |
| 커뮤니티 숫자는 믿기 어려움 | 고용24·KOSIS 숫자를 표기 그대로, 출처·기준 연도와 함께 |
| 취업·대학원·창업을 감으로 비교 | 같은 기준의 숫자 카드로 나란히 보고 '3년 뒤의 나'와 대화 |
| 알아본 뒤 무엇을 할지 막막함 | 오늘 해 볼 행동 1가지 + 국비 훈련과정 추천 |

## 03 AI를 활용한 해결 방안

**해결 방안 개요**: 질문이 들어오면 에이전트가 ① 관련 공공데이터(고용24 직업정보·훈련과정, KOSIS, 학과 진출 데이터)를 찾아 ② 숫자를 읽기 좋게 정리한 뒤 ③ 페르소나에 맞는 말투로 답하고 ④ 실제로 쓴 근거만 골라 답변 아래에 표시한다.

**왜 AI여야 하는가 (왜 일반 챗봇이 아닌가)**
- 데이터 사이트는 **정해진 표**를 보여 줄 뿐, "비전공자인데 될까요?" 같은 **내 질문**에 맞춰 골라 풀어 주지 못한다 → 대화형 AI가 필요
- 일반 챗봇은 대화는 잘하지만 **숫자를 지어내고, 학습 시점에 멈춰 있다** → 질문마다 공공데이터를 검색해 근거로 주는 구조(RAG)가 필요
- 모델을 다시 학습(미세조정)하지 않은 이유: 임금·통계는 해마다 바뀐다. 검색 증강은 **항상 최신 숫자**를 쓰고, 어떤 근거를 썼는지 **추적**할 수 있다

**AI 적용 지점**

| 페르소나 | 하는 일 | 근거 데이터 |
|---|---|---|
| 패널 사회자 | 학과·관심사를 듣고 직무 3~4개 추천 | 학과별 상위 진출 직업 |
| 직무 선배 | 일과·연봉·준비 방법·힘든 점을 선배 말투로 | 고용24 직업정보·훈련과정 |
| 패널 한마디 | 같은 질문에 관련 직무 선배 2명이 동시에 답해 비교 | 고용24 직업정보 |
| 3년 뒤의 나 | 갈림길을 3년 걸어 본 '미래의 나'가 1인칭으로 회고 | KOSIS 임금·취업률·생존율 |

모든 페르소나는 같은 4단 프롬프트 틀(① 맥락 ② 지침 ③ 응답 형식 ④ 일관성)을 쓴다. 숫자 규칙·말투·안전 규칙이 한곳에 있어 페르소나가 늘어도 품질이 흔들리지 않는다.

### AI의 한계와 대응

| 한계 | 대응 |
|---|---|
| 사실과 다른 내용 | 공공데이터를 먼저 검색해 근거로 넘기고, 쓴 근거를 항목별 표시. 나머지는 'AI 일반 지식'으로 명시 |
| 숫자 오류 | 숫자는 근거에 있을 때만 표기 그대로. 금액은 코드에서 미리 정리(10250만 원 → 1억 250만 원) |
| 데이터에 없는 직무 | 가장 가까운 직업 정보를 '관련 직업'으로 밝혀 소개 |
| 개인정보 입력 | 전화번호·이메일·주민번호 패턴은 AI에 보내지 않음 |
| 진로 단정 | 결과 보장 금지, 좋은 점·힘든 점 함께, 다른 선배 의견도 나란히 |
| 역할 이탈 요청 | 역할·말투 고정, 프롬프트 공개·역할 변경 요청 거절 |
| 응답 형식 오류 | 앱이 한 번 자동 재요청, 그래도 안 되면 다시 질문 안내 |

라이브 시험(2026-11-19) 5개 모두 통과: 숫자 그대로 인용 · 반말·의사 역할 요청 거절 · 프롬프트 공개 거절 · KOSIS 숫자+연도 회고 · 추천 형식 정상

## 04 서비스 구조

**구조도 (한 번의 질문이 처리되는 길)**
사용자 질문 → ① 개인정보 차단(패턴 감지 시 AI로 보내지 않음) → ② 근거 검색(직무·갈림길에 맞는 공공 API 호출, 하루 캐시) → ③ 근거 정리(금액 표기·핵심 숫자만 추림) → ④ LLM 생성(4단 프롬프트 + 근거 → 답변·사용 근거 JSON) → ⑤ 화면(대화체 답변 + 아래 근거 목록)

| 구분 | 내용 |
|---|---|
| 프론트/클라이언트 | Streamlit (다중 페이지·채팅 UI), Altair 차트, 모노톤 CSS, 휴대폰 대응 |
| 백엔드/에이전트 | Python, 근거 검색·정리 모듈, 페르소나 프롬프트, 병렬 호출(패널 한마디), 개인정보 패턴 차단 |
| AI 모델 | OpenAI gpt-5-mini (JSON 응답, reasoning_effort=low). 설정값으로 다른 모델 전환 가능 |
| 외부 API | 고용24 직업정보, 고용24 국민내일배움카드 훈련과정, KOSIS OpenAPI |
| 데이터(출처·라이선스) | 고용24(한국고용정보원, 공공누리 제4유형), KOSIS(통계정보활용약관), 상위진출직업(한국고용정보원, 공공데이터포털) |
| 배포 환경 | Streamlit Community Cloud(GitHub 자동 배포), API 키는 Secrets에만 보관 |

설계 포인트: 질문당 필요한 데이터만 호출해 응답 속도 개선(3년 뒤의 나 60초 → 8초), 사용 근거를 JSON으로 받아 출처를 정확히 표시

## 05 핵심 기능 및 사용자 흐름

- **핵심 기능 1 · 직무 선배와 대화**: 내 학과·직접 선택·패널 추천으로 직무를 고르면 그 직무 선배 AI가 일과·연봉·준비 방법을 답한다. 연봉은 고용24 숫자 그대로, 근거는 답변 아래, 국비 훈련과정 3개를 함께 추천 → **결과: 직무 현실 + 오늘 할 행동**
- **핵심 기능 2 · 패널 토론**: "다른 선배 의견도 듣기"를 누르면 같은 질문을 관련 직무 선배 2명에게 동시에 묻고 카드로 나란히 보여 준다 → **결과: 한 사람의 말이 아닌 여러 관점**
- **핵심 기능 3 · 3년 뒤의 나**: 취업·대학원·창업을 KOSIS 숫자 카드와 그래프로 나란히 비교하고, 고른 길의 '3년 뒤의 나'와 1인칭으로 대화 → **결과: 갈림길별 근거 있는 비교**

**Happy Path (민지, 약 3분)**
① 사회계열 → 경영학과 선택 → ② 추천 직무 '기획·마케팅 사무원' 고르기 → ③ "신입 연봉은 얼마예요?" → 고용24 숫자와 출처가 담긴 선배 답변 → ④ "다른 선배 의견도 듣기" → 관련 직무 선배 2명 비교 → ⑤ 3년 뒤의 나에서 취업·대학원·창업 숫자 비교 → ⑥ 대학원 길의 '3년 뒤의 나'와 대화

## 06 차별점

**한 줄 차별점**: 잡담은 **근거 있는 숫자 · 여러 사람의 관점 · 갈림길 비교**를 **하나의 대화**에서 제공하는 유일한 진로 도구다.

| 비교 항목 | 커뮤니티 (블라인드·카페 등) | 직업정보 사이트 (커리어넷·고용24) | 일반 AI 챗봇 | 잡담 |
|---|---|---|---|---|
| 숫자의 신뢰성 | 출처 불분명 | 공식 데이터 | 지어낼 수 있음 | 공공데이터 그대로 + 항목별 출처 |
| 내 질문에 맞춤 | 검색어 의존 | 정해진 항목 | 가능 | 가능 (질문마다 근거 검색) |
| 현직자 관점 | 개인 경험 1명 | 없음 | 일정치 않음 | 직무 선배 + 관련 직무 선배 2명 비교 |
| 갈림길 비교 | 어려움 | 통계표 직접 해석 | 근거 없는 비교 | KOSIS 숫자 카드 + 3년 뒤의 나 |
| 다음 행동 | 없음 | 일부 | 일반론 | 오늘 할 행동 + 국비 훈련과정 |
| 안전장치 | 없음 | - | 제각각 | 개인정보 차단 · 역할 고정 · 한계 공개 |

**사용자에게 주는 효과**: 들어가기 전에 근로여건(연봉·일과·힘든 점)을 확인 → 첫 직장 선택의 미스매치 감소 · 공공데이터가 청년의 실제 질문 속에서 쓰이는 구조

## 08 기대효과

- **청년 개인**: 현직자 없이도 직무의 현실을 근거와 함께 확인, 갈림길 비교로 선택의 불안 감소, 국비 훈련과정으로 '오늘 할 행동'까지 연결
- **대학·기관**: 진로센터 상담 전 단계 도구, 상담 인력이 부족한 지방 대학·청년센터 보완, 데이터 기반 구조로 기관별 확장 용이
- **사회·공공데이터**: 공공데이터가 청년의 실제 질문 속에서 활용, 출처 있는 진로 정보 문화 확산, 공공 API 조합의 저비용 구조
- **확장 로드맵**: 단기(커리어넷 연결, 인터뷰 자료 이용 허락 후 추가) · 중기(지역별 채용·훈련, 자격증 일정, 대화 요약 리포트) · 기관 연계(진로센터·청년센터 시범 운영)
