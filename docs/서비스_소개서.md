## 프로젝트 요약

- **한 줄 요약**: 공공데이터를 근거로 직무 선배 AI·패널 토론·'3년 뒤의 나'와 대화하며 청년이 진로를 비교·탐색하는 AI 에이전트
- **1 문제**: 물어볼 현직자가 없고 커뮤니티 정보는 출처가 불분명함 / 고용24·KOSIS 데이터는 있어도 직접 해석하기 어려움 / 취업·대학원·창업을 같은 기준으로 비교할 도구가 없음
- **2 해결 방안**: 질문마다 공공데이터를 실시간 검색해 근거로 넘기는 RAG 에이전트, 세 페르소나(직무 선배·패널 사회자·3년 뒤의 나), 숫자는 공공데이터 그대로·출처는 답변 아래
- **3 구현 현황**: 배포 운영 중, 고용24 직업정보·훈련과정·KOSIS 실시간 연동, 휴대폰 대응, 응답 60초 → 8초, 일관성 시험 통과
- **키워드**: 진로 탐색 · RAG · 공공데이터 · 페르소나 · 패널 토론 · 3년 뒤의 나 · 출처 표시 · 청년

## 01 문제 정의

| 문제 | 내용 |
|---|---|
| 물어볼 현직자가 없다 | 지방 대학·비전공자일수록 실제 일과·연봉·준비 방법을 들을 기회가 적음 |
| 정보의 출처를 믿기 어렵다 | 커뮤니티 후기·광고성 글은 숫자의 근거가 불분명하고 사람마다 말이 다름 |
| 공공데이터는 있지만 쓰기 어렵다 | 고용24 직업정보·KOSIS 통계표는 신뢰할 수 있지만 표가 복잡함 |
| 갈림길을 나란히 비교하기 어렵다 | 취업·대학원·창업을 같은 기준(임금·취업률·생존율)으로 볼 곳이 없음 |

해결 방향: 검색 결과 목록이 아니라 대화로 · 추측이 아니라 공공데이터 근거로 · 한 사람의 말이 아니라 여러 관점으로

## 02 대상 사용자

- **주요 사용자**: 진로가 막막한 대학생·졸업 예정자·사회초년생 (현직자 네트워크가 적은 지방 대학생·비전공자, 전공과 다른 직무를 고민하는 학생, 갈림길에서 망설이는 졸업 예정자, 이직을 고민하는 사회초년생)
- **보조 사용자·이해관계자**: 대학 진로·취업센터 상담사, 청년센터·고용센터, 학부모·멘토, 공공데이터 제공기관
- **사용자가 얻는 가치**: 현직자 접근성 · 믿을 수 있는 숫자(출처·기준 연도) · 여러 길의 비교

## 03 AI를 활용한 해결 방안

- **개요**: 질문 → 공공데이터 API 검색(RAG) → 근거 정리 → 페르소나 프롬프트 + 근거를 LLM에 전달 → 대화체 답변 + 사용한 근거 목록(JSON) → 답변 아래 근거 표시
- **왜 AI여야 하는가**: 같은 통계도 '내 질문'에 맞게 골라 풀어 주는 건 대화형 AI만 가능 / 관점을 바꿔 말하게 해 공감과 비교를 동시에 / 수백 개 직업·통계표를 질문할 때 바로 연결 / 미세조정 대신 검색 증강으로 해마다 바뀌는 숫자를 항상 최신으로
- **AI 적용 지점**

| 페르소나 | 하는 일 | 응답 형식 |
|---|---|---|
| 패널 사회자 | 학과·관심사·고민을 듣고 직무 3~4개 추천 | 해요체 2문장 + 추천 JSON |
| 직무 선배 | 선택한 직무의 일과·연봉·준비 방법·힘든 점 | 400~500자 대화체, 오늘 할 행동 + 되묻기 1개 |
| 패널 한마디 | 같은 질문에 관련 직무 선배 2명이 병렬 답변 | 150~250자, 자기 직무만의 관점 |
| 3년 뒤의 나 | 갈림길을 3년 걸어 본 미래의 나 | 1인칭 회고, KOSIS 숫자+연도, 마지막 조언 한 문장 |

공통 프롬프트 틀: 역할 → ① 맥락 → ② 지침 → ③ 응답 형식 → ④ 일관성 → 근거자료

### AI의 한계와 대응

| 한계 | 대응 |
|---|---|
| 사실과 다른 내용 | 공공데이터를 먼저 검색해 근거로 넘기고, 쓴 근거를 항목별 표시. 나머지는 'AI 일반 지식'으로 명시 |
| 숫자 오류 | 숫자는 근거에 있을 때만 표기 그대로. 금액은 코드에서 미리 정리(12500 → 1억 250만 원) |
| 데이터에 없는 직무 | 가장 가까운 직업 정보를 '관련 직업'으로 밝혀 소개 |
| 개인정보 입력 | 전화번호·이메일·주민번호 패턴은 AI에 보내지 않음 |
| 진로 단정 | 결과 보장 금지, 좋은 점·힘든 점 함께, 다른 선배 의견도 나란히 |
| 역할 이탈 요청 | 역할·말투 고정, 프롬프트 공개·역할 변경 요청 거절 |
| 응답 형식 오류 | 앱이 한 번 자동 재요청, 그래도 안 되면 다시 질문 안내 |

라이브 시험(2026-11-19) 5개 모두 통과: 숫자 그대로 인용 · 반말·의사 역할 요청 거절 · 프롬프트 공개 거절 · KOSIS 숫자+연도 회고 · 추천 형식 정상

## 04 서비스 구조

구조도: 사용자 → Streamlit 앱(화면·세션·개인정보 차단) → 근거 검색(질문마다 API, 하루 캐시) → 근거 정리(금액·통계 요약) → LLM(4단 프롬프트, 답변+근거 JSON) → 화면(답변 + 아래 근거)

| 구분 | 사용 기술 |
|---|---|
| 프론트/클라이언트 | Streamlit 1.67 (다중 페이지·채팅 UI), Altair 차트, 모노톤 CSS, 휴대폰 대응 |
| 백엔드/에이전트 | Python 3, 근거 검색/정리 모듈, 페르소나 프롬프트, 병렬 호출, 개인정보 패턴 차단 |
| AI 모델 | OpenAI gpt-5-mini (Chat Completions, JSON 모드, reasoning_effort=low), Anthropic Claude 전환 가능 |
| 외부 API | 고용24 직업정보, 고용24 국민내일배움카드 훈련과정, KOSIS OpenAPI, 커리어넷(키 발급 대기) |
| 데이터(출처·라이선스) | 고용24(공공누리 제4유형·OPEN-API 약관), KOSIS 통계정보활용약관, 상위진출직업(공공데이터포털) |
| 배포 환경 | Streamlit Community Cloud(GitHub 자동 배포), 키는 Secrets, 사용자 키(BYOK)는 세션에만 |

## 05 핵심 기능 및 사용자 흐름

- **핵심 기능 1 · 직무 선배와 대화**: 학과·직접 선택·패널 추천으로 직무를 고르면 현직 선배 AI가 연봉·일과·준비 방법을 답함. 숫자는 고용24 그대로, 근거는 답변 아래, 국비 훈련과정도 함께
- **핵심 기능 2 · 패널 토론**: 같은 질문을 관련 직무 선배 2명에게 동시에 물어 카드로 비교
- **핵심 기능 3 · 3년 뒤의 나**: 취업·대학원·창업을 KOSIS 숫자 카드·그래프로 비교하고 미래의 나와 1인칭 대화
- **Happy Path**: 학과 선택(사회계열 → 경영학과) → 직무 고르기(기획·마케팅 사무원) → 선배 질문("신입 연봉은 얼마예요?") → 다른 선배 의견 → 갈림길 비교 → 3년 뒤의 나와 대화

## 08 기대효과

- **청년 개인**: 현직자 없이도 직무의 현실을 근거와 함께 확인, 갈림길 비교로 선택의 불안 감소, 국비 훈련과정으로 '오늘 할 행동'까지 연결
- **대학·기관**: 진로센터 상담 전 단계 도구, 상담 인력이 부족한 지방 대학·청년센터 보완, 데이터 기반 구조로 기관별 확장 용이
- **사회·공공데이터**: 공공데이터가 청년의 실제 질문 속에서 활용, 출처 있는 진로 정보 문화 확산, 공공 API 조합의 저비용 구조
- **확장 로드맵**: 단기(커리어넷 연결, 인터뷰 자료 이용 허락 후 추가) · 중기(지역별 채용·훈련, 자격증 일정, 대화 요약 리포트) · 기관 연계(진로센터·청년센터 시범 운영)
