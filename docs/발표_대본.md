# 3분 발표 대본 + 예상 질문

## 대본 (약 3분)

**[0:00 문제]**
청년의 첫 직장 평균 근속기간은 1년 6.8개월입니다. 그만둔 이유 1위는 보수·근로시간 같은 근로여건 불만족, 44.4%입니다. 들어가기 전에 그 직무의 현실을 알 방법이 없었다는 뜻입니다. 물어볼 현직자는 없고, 커뮤니티 숫자는 믿기 어렵고, 공식 데이터는 너무 어렵고, 알아본 뒤에도 무엇부터 할지 막막합니다.

**[0:20 해결]**
그래서 저희는 '잡담'을 만들었습니다. 나를 알고, 직무를 묻고, 갈림길을 비교하고, 로드맵을 받는 4단계 진로 에이전트입니다. 모든 숫자는 공공데이터 8종에서 실시간으로 가져옵니다.

**[0:35 ① 직무 간이검사 → ② 직무 패널]**
경영학과 4학년 민지입니다. 먼저 흥미와 가치관, 강점을 고르는 간이검사를 합니다. 그다음 직무 패널에서 데이터분석가를 고르면, 간이검사 결과와 고용24 직업별 성향 점수를 비교한 적합도가 나옵니다. AI의 추측이 아니라 코드로 계산한 값입니다.

**[0:55 선배와 대화 · 회사 정보]**
선배에게 "신입 연봉은 얼마예요?"라고 묻습니다. 에이전트는 고용24 직업정보와 커리어넷 직업백과를 먼저 찾고, 그 숫자를 그대로 쓴 선배 말투의 답을 만듭니다. 근거는 답변 아래에 붙습니다. "갈 만한 회사"를 물으면 청년친화강소기업, DART, 국민연금 데이터에서 실제로 찾은 회사만 직원 수와 함께 소개합니다.

**[1:40 ③ 3년 뒤의 나]**
이제 갈림길입니다. 간이검사와 고른 직무를 종합해 맞는 길을 참고로 추천하고, 취업·대학원·창업을 KOSIS 통계로 나란히 봅니다. 대학원을 고른 '3년 뒤의 나'에게 물으면, 대학원 취업률 같은 숫자와 연도를 넣어 1인칭으로 돌아봅니다.

**[2:10 ④ 커리어 로드맵]**
마지막으로 '이 길로 커리어 로드맵 만들기'를 누르면, 지금의 나에서 3년 뒤의 나까지 도로 위 이정표 4개가 그려집니다. 단계별 할 일은 AI가 제안하고, 자격·시험일정·국비 교육은 공공데이터에 실제로 있는 것만 남깁니다.

**[2:35 신뢰와 마무리]**
AI는 틀릴 수 있습니다. 그래서 숫자는 근거에 있을 때만 쓰고, 회사 이름은 지어내지 않으며, 개인정보는 AI로 보내지 않습니다. 잡담은 정답을 주는 서비스가 아닙니다. 근거 있는 숫자와 여러 관점으로, 청년이 들어가기 전에 스스로 비교하고 고르고, 오늘부터 움직이게 돕습니다. 감사합니다.

## 예상 질문 12개

1. **왜 파인튜닝(미세조정)을 안 했나요?** → 임금·통계는 해마다 바뀝니다. 질문할 때마다 최신 공공데이터를 검색해 근거로 쓰는(RAG) 쪽이 정확하고, 어떤 근거를 썼는지 추적할 수 있습니다.
2. **AI가 숫자를 틀리게 말하면?** → 숫자는 근거에 있을 때만 표기 그대로 쓰게 했고, 금액은 코드에서 미리 정리해 넘깁니다. 쓴 근거는 답변 아래에 표시해 사용자가 확인할 수 있습니다.
3. **일반 챗봇(ChatGPT)과 뭐가 다른가요?** → 일반 챗봇은 숫자를 지어낼 수 있고 학습 시점에 멈춰 있습니다. 잡담은 질문마다 공공 API 8종을 불러 근거를 붙이고, 간이검사로 나를 반영하며, 직무 선배·패널·미래의 나처럼 관점을 바꿔 비교한 뒤 로드맵으로 이어 줍니다.
4. **데이터에 없는 직무를 물으면?** → 고용24에서 가장 가까운 직업 정보를 '관련 직업'으로 밝혀 소개하고, 나머지는 AI 일반 지식이라고 표시합니다.
5. **개인정보는 어떻게 다루나요?** → 회원가입이 없고 저장하지 않습니다. 전화번호·이메일·주민번호 패턴은 AI로 보내기 전에 차단합니다.
6. **운영 비용은?** → 팀 키는 접속당 질문 20개로 제한하고 OpenAI 월 한도를 걸었습니다. 원하는 사용자는 자기 API 키를 쓸 수 있고, 키는 저장하지 않습니다.
7. **응답 속도는?** → 선배 답변 약 13초, 선배 두 명 비교 약 18초(병렬 호출), 3년 뒤의 나 약 8초, 회사 질문 10~25초, 로드맵 약 20초입니다. 원자료 대신 핵심 숫자만 넘겨 3년 뒤의 나를 60초에서 8초로 줄였습니다.
8. **'3년 뒤의 나'가 미래를 예측하는 건가요?** → 예측이 아닙니다. 그 길의 공식 통계와 일반적인 경험을 1인칭 회고로 들려주고, 사람마다 상황이 다르다는 점을 함께 말합니다.
9. **확장 계획은?** → 커리어넷 공식 직업심리검사 연동, 강소기업 지역 선택, 공공기관 채용 연계, 대화 요약 리포트, 대학 진로센터·청년센터 시범 운영입니다. 직무·학과·통계표를 데이터로 관리해 코드 수정 없이 늘릴 수 있습니다.
10. **공공데이터 라이선스는 지켰나요?** → 고용24 직업정보는 공공누리 제4유형이라 원문을 고치지 않고 출처와 함께 인용합니다. KOSIS는 통계정보활용약관에 따라 출처를 표시합니다. 커리어넷은 공공누리 제1유형, DART·국민연금·Q-Net도 각 기관 약관에 따라 출처를 답변 아래에 표시합니다.

11. **직무 적합도는 믿을 만한가요?** → AI가 정하지 않습니다. 간이검사 결과와 고용24 직업별 흥미·가치관·능력 점수를 코드로 비교한 참고 지표이고, 간이검사는 공식 검사가 아니라고 화면에 밝힙니다. 공식 검사 결과를 넣으면 그걸 우선 씁니다.
12. **회사 정보는 어디서 오나요? 지어내지 않나요?** → 고용24 청년친화강소기업, DART 전자공시, 국민연금 가입 사업장에서 실제로 찾은 회사만 소개합니다. 못 찾으면 "찾지 못했어요"라고 하고, 채용 중인지는 알 수 없다고 함께 말합니다.
